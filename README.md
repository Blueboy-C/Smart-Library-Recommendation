# 智慧图书馆个性化学习推荐系统

基于AI的高校个性化学习推荐平台，融合图书馆借阅数据与教务选课成绩数据，通过协同过滤与内容推荐算法为学生提供个性化图书、课程、学术活动推荐，并通过大语言模型（LLM）实现智能推荐解释、学习路径规划、跨领域兴趣发现与对话助手等智能化功能。

## 技术栈

- **推荐引擎**: User-Based CF + TF-IDF 余弦相似度（混合推荐）
- **LLM集成**: 推荐解释、学习路径规划、对话助手、语义检索、教师洞察报告
- **前端**: Web端（待定技术栈）
- **后端**: Python（待定框架）
